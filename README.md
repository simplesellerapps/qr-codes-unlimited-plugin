# QR Codes Unlimited

Create, style and manage QR codes from Claude Code or Codex using our hosted MCP service.

- [Download the validated plugin ZIP](https://github.com/simplesellerapps/qr-codes-unlimited-plugin/releases/latest)
- [Installation, account access and data-use guide](plugin/README.md)
- [Public reviewer walkthrough](https://simplesellerapps.github.io/qr-codes-unlimited-plugin/)
- [Service website](https://qrcodesunlimited.com)

The distributable plugin lives in **`plugin/`**. Directory submissions should use that subfolder on the `main` branch. Root marketplace indexes point to the same folder. The `docs/` folder hosts the reviewer recordings separately from the plugin package.

The plugin's manifests, skills and documentation use the MIT license. Brand assets, recordings and the hosted service retain their existing rights; see [NOTICE](NOTICE).
